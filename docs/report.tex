\section{Rules-compliance statement}
\begin{itemize}[nosep]
  \item No third-party engine, wrapper, port or translation is shipped or consulted at runtime.
  \item No published network is shipped; Stage 0 ships no network at all.
  \item No lookup database of another engine's moves or evaluations ships in the zip.
  \item Memorised-code risk: every table is generated by \texttt{tools/gen\_pst.py} from a
        parametric geometric prior with recorded parameters; search and evaluation were written
        against a module contract (\texttt{docs/DESIGN.md}) from textbook descriptions, and every
        constant is listed in Appendix~\ref{app:provenance}.
  \item Everything shipped is plain, type-annotated Python that passes \texttt{ruff} and
        \texttt{mypy --strict}.
\end{itemize}
